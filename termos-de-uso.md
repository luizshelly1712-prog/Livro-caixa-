**Última atualização:** 17/08/2026

## 1. Sobre o aplicativo
O Livro-Caixa é uma ferramenta para registro pessoal de receitas e despesas,
com cálculo de totais, categorização e (na versão com login) sincronização
entre dispositivos.

- Você é responsável pela veracidade dos dados informados no cadastro (e-mail).

## 3. Uso permitido
O aplicativo deve ser usado apenas para fins pessoais e lícitos de controle
financeiro. É proibido:
- Tentar acessar dados de outros usuários;
- Usar o aplicativo para fins ilegais;
- Tentar interferir no funcionamento do aplicativo ou dos servidores.

## 4. Natureza da ferramenta — isenção de responsabilidade
O Livro-Caixa é uma ferramenta de **registro e organização** de informações
financeiras que você mesmo insere. Ele:
- **Não** oferece consultoria financeira, contábil, tributária ou de
  investimentos;
- **Não** garante a exatidão de cálculos caso os dados inseridos estejam
  incorretos;
- **Não** se responsabiliza por decisões financeiras tomadas com base nas
  informações do aplicativo.

Para decisões financeiras importantes, recomendamos consultar um profissional
qualificado (contador, planejador financeiro, etc.).

Fazemos esforços razoáveis para manter o aplicativo disponível, mas não
garantimos funcionamento ininterrupto ou livre de erros. Manutenções,
instabilidades de terceiros (ex.: provedor de nuvem) ou falhas técnicas podem
ocorrer.

## 6. Dados e backup
- Na versão local (sem login), os dados ficam salvos apenas no seu navegador.
  A perda desses dados (ex.: ao limpar o navegador, trocar de aparelho ou
  desinstalar) é de responsabilidade do usuário.
- Na versão com login, os dados são sincronizados na nuvem, mas recomendamos
  que você mantenha práticas próprias de conferência periódica das
